# SD-018: First offline reload accepts a safe Origin variant

Status: Prepared for review, independently based on main `aefd7fe`.

Trigger: production preview precaches headerless asset requests with Vary: Origin.
Module/style requests supply Origin, so strict matching returns 503 for stored
JS/CSS before the first worker-controlled online reload.

Outcome: allow the exact public precache URL to reuse an Origin-only variant.
Private/unlisted URLs, query variants, Cookie/mixed Vary and wildcard Vary keep
strict behavior. No navigation HTML fallback for assets.

Evidence: [report](../evidence/SD-018/report.md). Check/79 tests/build pass;
browser first-visit/restart/rotation cold reloads pass on the integrated build.
This justified one exception to the occupied five-slot target; no overlapping
batch or balance/policy change was added.
